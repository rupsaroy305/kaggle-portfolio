# ARC Research Toolkit: Object, Shape & Pattern Analysis

A comprehensive exploratory analysis (EDA) toolkit for **ARC-AGI** tasks developed for **The 2026 NeuroGolf Championship**. The notebook focuses on understanding ARC tasks through object detection, geometric analysis, visualization, shape comparison, and dataset-level exploration rather than building task-solving models.

## Overview

This project provides a modular research toolkit for analyzing ARC tasks. It includes utilities for detecting objects, extracting geometric features, visualizing transformations, comparing shapes, generating task reports, and exploring dataset-wide statistics.

## Features

* Connected-component object detection
* Bounding box extraction
* Shape analysis
* Pattern analysis
* Shape similarity metrics
* Automatic task reports
* Visualization dashboard
* Dataset-wide statistical exploration
* Research archive generation
