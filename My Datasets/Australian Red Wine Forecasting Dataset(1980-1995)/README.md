# Red Wine Time Series Forecasting

Time series analysis and forecasting of monthly Australian red wine data. The project includes trend estimation, seasonal index calculation, classical time series decomposition, and visualization for forecasting applications.

* Trend Analysis
* Seasonal Index Calculation
* Ratio-to-Moving-Average Method
